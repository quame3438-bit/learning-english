# 英语逐句听力

直接把本文件夹中的全部文件上传到 GitHub 仓库根目录：

- index.html
- sw.js
- manifest.webmanifest
- icon.svg

然后到 GitHub：
Settings → Pages → Deploy from a branch → main / root → Save

主要功能：
- 显示：中英 / 中文 / 英文 / 不显示
- 速度调节
- 时间间隔
- 播放完自动停止
- 单句循环
- A/B 定点循环
- 1~100遍或无限后播放下一句
- 上一句 / 播放本句 / 下一句
- 整体播放 / 暂停
- 波形进度条拖动定位
- 选中字幕后翻译与发音
- SRT / VTT / TXT 字幕导入
- PWA，可添加到手机主屏幕
