# 英语逐句听力 v4

本版重点修改：

- “播放完自动停止 / 单句循环 / （ ）遍后播放下一句”合并成一个下拉菜单，只能选择一种模式。
- 选择“（ ）遍后播放下一句”后，才显示“遍数”和“时间间隔”。
- 遍数保留：0、无限、1～100。
- 0 表示本句播放一次后停止，不自动进入下一句。
- A/B 循环按钮：点一次开启，再点一次关闭。
- 快退 / 播放暂停 / 快进布局保留。
- 快退和快进秒数仍可分别选择 1～10 秒。
- 波形、字幕导入、显示中英/中文/英文、翻译和发音功能保留。

部署：
解压后把全部文件上传到 GitHub 仓库根目录。
如网页仍显示旧版，可在网址末尾加 ?v=4 打开一次。
