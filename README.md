# 英语逐句听力 v3

本版修改：
- 播放/暂停左侧为“快退”，右侧为“快进”
- 快退和快进各自可选择 1～10 秒，默认 5 秒
- A / A-B循环 / B 单独放在下一行，并与上方三列对齐
- A/B循环继续支持 A-B 区间循环
- 波形进度条、字幕导入、逐句播放、翻译、发音等功能保留

GitHub 新仓库部署：
1. 解压 ZIP。
2. 把 index.html、sw.js、manifest.webmanifest、icon.svg、README.md 全部上传到仓库根目录。
3. Settings → Pages → Deploy from a branch → main / root → Save。
4. 如果手机仍显示旧版，请网址末尾临时加 ?v=3 打开一次。
